# Bundled typefaces

- Fusion Pixel Font 12px monospaced, Simplified Chinese, release 2026.09.25: https://github.com/TakWolf/fusion-pixel-font . The release's full license directory is preserved in `fusion-licenses/`.
- Noto Serif SC, static weight 400 instantiated from Google Fonts' variable font: https://github.com/google/fonts/tree/main/ofl/notoserifsc . License: `noto-serif-OFL.txt`.

Both fonts are bundled for offline use under the SIL Open Font License. Preview and MP4 export use glyphs rasterized from these exact files.
