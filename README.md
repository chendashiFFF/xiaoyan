# 小言 · 影像诗集

围绕艺术主题创作歌词视频的本地工作台。视频工作台与人物工坊共享人物、动作、图片服务和素材文件。

## 启动

本机需要 Node.js 22.18+、Python 3.9+ 和 FFmpeg（含 ffprobe）。macOS 可用 `brew install ffmpeg` 安装视频编码工具。

```bash
npm run setup  # 首次安装 Python 和前端依赖
npm start      # 构建并启动
```

- 原版人物动作工作台（首页）：http://127.0.0.1:5180/
- 视频工作台：http://127.0.0.1:5180/video/
- 人物工坊：http://127.0.0.1:5180/characters/
- 开发：`npm run dev`，打开 http://localhost:5173/ 。快捷命令面向 macOS / Linux。

桌面宠物、透明置顶窗口与 Electron 打包入口已移除。**人物生成、动作生成、修帧和补帧工作台已保留**，打开首页即可使用。人物工坊的原有动作、参考图、历史版本和导出文件均保留。

## 人物参考图库

新人物默认可直接上传 1–6 张原始参考图，无需先生成规范图。创建后在“角色参考”中继续追加图片、标记正面／偏转／侧面／背面／细节，设置默认启用图片和尺寸基准。原上传文件另存于人物的 `references/originals/`，去背景等处理不会覆盖它。

动作编辑区的“本次参考图片”可临时勾选图片，并选择保留道具或只参考人物；选择适用于新动作、重绘、局部修补及批量补帧。全部勾选图片都会发送，服务限制引起的错误直接显示，不会静默丢弃图片。每次任务保存参考图快照和角度、道具选项，可在任务历史中查看。移除图库图片保留磁盘文件和旧任务快照。旧人物已有参考图默认启用，规范图和三视图生成仍作为可选功能保留。

## 三个创作步骤

### 1. 场景与风格

- “月下书房”“雨夜电台”“落日手记”三套艺术方向联动配色、字体、对话框、镜头与环境动效。
- 选择人物，再描述场景；背景生成以该人物的动作图片作为画风参考，对话框生成另外参考当前背景。生成结果作为素材入库，点击采用后才应用，不覆盖原始素材。
- 背景与对话框生图使用“生图设置”中的图片 API，与人物工坊共用 `studio/settings.local.json`；密钥不会返回浏览器。未配置时明确提示，不会假装生成成功。若服务返回分组未开启生图的 403，需在服务后台启用该权限或更换密钥；工作台无法替服务商开通权限。
- 背景上传支持 PNG / JPEG / WebP；人物建议使用透明 PNG。内置雨夜房间标记为“构图草图”，不是 AI 生成的最终美术。
- 对话框支持可缩放主题边框或生成/上传的九宫格素材，歌词单独渲染，不烘焙到图片里。
- 背景可添加雨、雪、萤火或微尘；8 秒循环的轻微运镜与暖光呼吸使静图产生动态。此版本不是 AI 视频生成或语义物体动画。

### 字体与排版

内置开源的融合像素和思源宋体，授权文件在 `assets/fonts/`。也可以上传 TTF / OTF（最多 30 MB）。支持字距、行距、字号、对齐、文字和高亮颜色、描边、投影及框内留白。

预览与 MP4 使用**同一份服务端字形图集和排版坐标**，不依赖浏览器的系统替代字体。缺字和歌词溢出会提示并阻止导出。构图阶段暂停时展示完整歌词便于排版；播放时按真实时间显示。

### 2. 歌词与演出

- 导入 MP3 / WAV / M4A / OGG / FLAC / AAC，最长 10 分钟、64 MB。
- 显示歌曲的真实音频波形，可以拖动播放位置试听。
- 导入 TXT / LRC 或粘贴歌词。LRC 读取时间戳和 offset；普通文本均分时长，之后手动校准，不包含自动演唱对齐。
- 每句可设置起止时间与人物动作，支持拆句、删除和在时间空隙中新增歌词。
- 逐字浮现、整句显示或逐字高亮。逐字效果在句内匀速分配；间奏显示歌名。
- 在人物工坊新增动作后返回视频工作台或点击“刷新人物工坊素材”即可使用。

### 3. 预览与成片

输出 720×1280 或 1280×720，24 FPS、H.264 视频、AAC 音频。导出使用提交时的快照，有进度、取消和下载；未导入歌曲时输出静音视频。

## 数据与恢复

- `studio/music/document.json`：点击保存后的当前作品。浏览器另存未保存草稿，刷新或往返人物工坊会恢复。
- `studio/music/templates.json`：收藏的完整视觉主题（含字体、背景、人物、构图和动效，不含歌曲和歌词）。旧版浏览器模板仍可读取。
- `studio/music/media/`、`catalog.json`：上传图片、字体、生成素材与动作缓存。
- `studio/music/art-jobs/`：场景生成的提示词、参考素材记录、日志和结果。
- `studio/music/exports/`：完成的 MP4。
- `studio/projects/` 与 `assets/`：原有人物、逐帧动作、参考图与旧导出，未删除。
- `studio/settings.local.json`：本机图片服务配置，不加入 Git。

复制整个 `studio/music/` 可备份视频作品；同时备份 `studio/projects/` 可保留人物工坊。当前视频编辑器编辑一个作品，换歌前可保存目录副本。生成/导出进度存在内存，重启会中断进行中的任务；已经完成的素材与视频仍在磁盘。

如果首次安装的人物库为空，可以执行 `npm run studio:import` 导入自带动作。默认跳过已经存在的动作；`-- --force` 会覆盖动作，使用前请备份。

## 验证

```bash
npm run build
npm test
```

测试使用临时目录，不修改用户素材。覆盖歌词时间、LRC、图片处理、字体排版与缺字检查、主题保存、原人物工坊接口、未配置生图服务的错误提示、取消导出，以及横竖屏带音频的 MP4 编码。缺少 FFmpeg 时跳过编码测试。测试工具需 `httpx`（包含在依赖中）。

服务默认只监听本机 `127.0.0.1`。MIT License；字体遵循各自的 SIL Open Font License，详见 `assets/fonts/README.md`。

生图设置在两个工作台中共用，打开设置时读取最新值。点击“保存并测试出图”会使用已有的人物动作图片和参考图，沿用原版重绘流程生成一张候选图并预览；不会自动采用或覆盖原动作。模型列表连接测试不能证明出图权限，实际请求失败时展示服务返回的原因。
